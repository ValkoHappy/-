# Ответ цифрой

Удобная переписка по SMS с человеком на **кнопочном телефоне**.
Вы присылаете вопрос с пронумерованными вариантами, собеседник отвечает **одной цифрой**.

```
#12 Купить хлеб?          ← приходит на кнопочный телефон
1-да
2-нет

2                         ← ответ: одна кнопка
```

У собеседника ничего устанавливать не нужно, подойдёт любой телефон, который умеет SMS.
У вас — веб-приложение (работает в браузере телефона, можно установить на экран).

## Правила для того, кто отвечает

| Что пришло | Что ответить | Пример |
|---|---|---|
| Один вопрос с вариантами | одну цифру | `2` |
| Вопрос «(можно неск. цифр)» | цифры подряд | `13` = 1-й и 3-й |
| Анкета: вопросы А) Б) В) | по цифре на каждый вопрос, подряд | `213` |
| Нужно поговорить | `0` | «позвони мне» |
| Ответ на старый вопрос | номер, пробел, цифра | `12 1` |

Что ещё понимает приложение:

- **Буквы вместо цифр.** Если в буквенном режиме нажать кнопку «2» один раз, получится «а».
  Приложение понимает это как 2 (в русской и латинской раскладке, кнопка «1» → «.»).
- **Ответ словами:** «да», «нет», «ага», «позвони», название варианта или его начало («завт» → «завтра»).
- **Разделители не важны:** `2 1 3`, `2-1-3`, `12#3`, `12*3`.
- **Обычный текст** («купи ещё масла») тоже сохраняется в переписке, просто без разбора.

Во вкладке «Памятка» эти правила собраны на карточке: её можно распечатать и положить рядом
с телефоном или отправить собеседнику по SMS.

## Как пользоваться

1. **Настройки** → укажите имя и номер собеседника. Собеседников может быть несколько.
2. **Спросить** → выберите шаблон или напишите вопрос и варианты (до 9).
   «+ Ещё вопрос в это же SMS» делает анкету из нескольких вопросов.
   Внизу видно, как будет выглядеть SMS и во сколько сообщений оно влезет.
3. **Отправить SMS** открывает стандартное приложение сообщений с готовым текстом.
4. Когда придёт ответ, скопируйте его и вставьте во вкладке **Ответы** (кнопка «Вставить»).
   Если приложение установлено на Android, можно выделить SMS → «Поделиться» → «Ответ цифрой».
5. Ответ можно отметить и вручную: нажмите нужный вариант у вопроса (например, если ответили по телефону).

### Про длину SMS

Кириллица помещается в одно SMS только до **70 символов** (латиница — 160).
Счётчик под превью показывает длину и предупреждает, если сообщение разобьётся на части.
Для старых телефонов без русских букв или чтобы влезло больше, включите **«Латиницей»**:
`#12 Kupit hleb? 1-da 2-net`.

## Запуск

Сборка не нужна, это статические файлы.

- **Локально:** `python3 -m http.server 8000` в папке проекта → http://localhost:8000
- **На телефоне:** опубликуйте папку на любом HTTPS-хостинге, например GitHub Pages
  (Settings → Pages → Deploy from a branch → эта ветка, папка `/`).
  По HTTPS приложение работает без интернета и устанавливается на главный экран;
  на Android оно появляется в меню «Поделиться».

Данные хранятся только в браузере (`localStorage`). В настройках есть «Сохранить копию» / «Загрузить копию».

## Устройство

| Файл | Что делает |
|---|---|
| `js/protocol.js` | Логика протокола без интерфейса: формат SMS, длина, транслит, разбор ответа |
| `js/app.js` | Интерфейс |
| `index.html`, `styles.css` | Разметка и стили |
| `manifest.webmanifest`, `sw.js` | Установка на экран, офлайн, «Поделиться» |
| `tests/protocol.test.js` | Тесты протокола: `node --test tests/*.test.js` |

### Как разбирается ответ

1. Номера вопросов всегда двузначные (`#10`…`#99`, по кругу), поэтому их нельзя спутать с ответом-цифрой.
2. Цифры без номера относятся к **последнему вопросу без ответа**. Если все отвечены, это исправление последнего.
3. `12 3` (или слитно `123`, если для последнего вопроса это не подходит) — ответ на вопрос #12.
4. `0` — просьба позвонить.
5. Нет цифр: сначала слова («да», «позвони», название варианта), потом буквы-нажатия кнопок.
6. Если ничего не подошло, сообщение сохраняется как обычный текст.

`js/protocol.js` работает и в Node, поэтому его можно подключить к SMS-шлюзу
(например, Android-телефон с приложением-шлюзом), чтобы ответы разбирались без копирования.
